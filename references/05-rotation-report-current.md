# 05 Rotation Report Current｜六部分深度报告

## 一、核心结论

只能写一个高信息密度段落。先看宏观环境，再概括真正的轮动；不得拆成多段，也不得与第二、第三部分重复。

这一段必须同时回答：

- 市场当天/当周有没有真实热点；
- 是否处于重大宏观事件前等待期；
- 最强轮入、最强轮出、次级方向；
- 大盘/小盘、成长/价值、周期/防御、硬件/软件、高久期/低久期是否有真实切换；
- 哪些是板块信号，哪些只是公司级或样本噪声。
- 最重要的行情性质变化或维持。

不提前写持续性评级，不写重复总结。

## 二、当天板块轮动情况 / 本周板块轮动情况

后台从五个股票范围各自涨3/跌3及Themes涨3/跌3建立完整覆盖集合；第二节不展示该内部集合，也不机械罗列全部项目。

### 选取规则

1. 分别计算每个方向在 All Stocks、S&P 500、Dow Jones 30、Nasdaq 100、Russell 2000、Themes 中进入涨3或跌3的频率。
2. 名称相近、底层成分高度交叉且经济敞口实质相同的方向先合并；仅共享宏观叙事不能合并。
3. 按频率从高到低，结合代表ETF、跨范围宽度、权重股、准确相对收益和可得真实基金流量复核，严格选出轮入3项和轮出3项。
4. 频率相同时，依次以独立范围印证数、宽度、代表ETF与权重股同步性、信号代表性决定排序。

### 固定表格

表格必须恰好6行，严格只有四列，禁止增加、删除或改名：

| 轮动强度 | 板块和主题 | 当日表现情况 | 轮动分析 |
|---|---|---|---|
| 轮入1 |  |  |  |
| 轮入2 |  |  |  |
| 轮入3 |  |  |  |
| 轮出1 |  |  |  |
| 轮出2 |  |  |  |
| 轮出3 |  |  |  |

周报将第三列标题改为“本周表现情况”，其余不变。

“当日/本周表现情况”写准确涨跌幅、板块宽度、范围之间及代表ETF/权重股的印证或背离。“轮动分析”必须综合相对收益、权重、上涨/下跌家数和可获得的真实基金流量，明确属于最强轮入、温和轮入、最明确轮出、次级轮出、公司级冲击、表面轮出或样本结构失真。不能用微盘股或单只权重股机械外推板块。

## 三、驱动因素、盈利预期和持续性

只分析第二节最终筛出的三项轮入和三项轮出，不把其余涨3/跌3后台项目重新展开，也不加入其他方向。每个不同板块或主题都单独设小标题并获得与重要性匹配的解释；样本结构或单一公司扭曲的入选方向可以简写，但不能跳过。

只有名称、底层成分和盈利来源均高度重合的方向可合并，例如能源与能源商品。半导体、工业、清洁能源等不同板块必须分别分析，不能因同受AI资本开支、电力需求或宏观因素影响而合并。

每个方向依次写：

1. 直接触发；
2. 产业和宏观背景；
3. 最新财报、指引、订单、利润率、资本开支、信用、商品价格等对盈利预期的影响；
4. 行情性质若为上涨/下跌趋势，才增加“趋势继续成立需要的条件 / 破坏条件”。

大型震荡、头部、底部到第3项结束，不再加持续性内容。

如果没有同日/同周直接催化，直接写清产业、宏观、权重或样本结构的具体解释；不需要把检索过程或“暂未找到”这类后台核验口径写进正式轮动报告。

## 四、行情性质

表格只列：

- 板块/代表ETF；
- 行情性质；
- 1—2句必要说明（可直接放在行情性质单元格）。

合法标签只有：上涨趋势、下跌趋势、大型震荡、头部、底部。

状态必须先继承上一期，再判断是否满足变更条件。

涨3/跌3去重集合中每个具有板块/主题意义的项目必须列入本节。历史或 ledger 没有记录时，在后台检查历史资料和近期真实价格结构，从五种合法状态中补建分类并同步加入唯一 ledger；不得留白、暂不分类或略过。

正式表格只写板块/代表ETF与最终行情性质，不得出现“初始性质”“新增”“建档”“作者历史”“ledger”“强制覆盖”等后台话术。

## 五、商品涨跌驱动判断

明显涉及商品时逐项分析：

- 当前五类行情性质；
- 当日/当周涨跌；
- 宏观触发；
- 库存、产量、矿山/油田、进出口、季节、政策、美元、利率等真实供需；
- 股票端经营杠杆、盈利弹性、成本、产量、品位、套保、资本开支。

黄金、白银、铂族分开；工业金属区分供需与宏观/政策交易。

只有上涨/下跌趋势写趋势维持条件。其余三类只分析现状。

无显著商品主线时明确写：

> 当日无需要专项展开的显著商品板块主线。

周报改“本周”。

## 六、未来观察点

只写未来真正可能改变定价、盈利预期或行情性质的验证信号：

- CPI/PPI/就业/FOMC；
- 长端利率、美元；
- 龙头财报、订单、指引；
- 商品库存、供应、物流；
- 板块宽度是否扩散/收缩；
- 趋势继续成立的现实验证。

**不再做全文总结，不再做持续性排行榜，不再增加“最终结论”。**

## 正式成稿语言与信息边界

- 公司名称可保留英文并带股票代码；除公司外，所有板块、主题、子行业、子主题名称统一写中文，不得中英混用。
- 后台可以读取Bloomberg节目研究、宏观上下文、历史报告与state ledger；正文只呈现消化后的事实和判断。
- 禁止在正文出现“节目/彭博/字幕提到、支持、验证、反映”“作者”“作者历史”“初始性质”“强制覆盖”“必须进入报告”“后台”“修改建议”“纠正”等生成过程话术。
