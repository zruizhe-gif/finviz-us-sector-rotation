# 04 Consistency-First Statistics｜涨3/跌3最高优先级

本文件把原任务最重要的统计前置规则单独提升为运行时强制检查。其内容与原任务一致，不是新发明的规则。

## 五个股票范围

对每个范围内**每一个板块的全部有效成分股**，计算：

- 有效成分总数；
- 上涨家数；
- 下跌家数；
- 平盘家数；
- 上涨占比；
- 下跌占比；
- 板块整体收益率。

定义：

- 全部有效成分收益率严格 `> 0`：清一色上涨；
- 全部严格 `< 0`：清一色下跌；
- 只要含0或方向混合：不属于清一色。

### 上涨前三

1. 先收集全部清一色上涨板块；
2. 在这些候选中按既定板块整体表现从高到低排序；
3. 优先取前3；
4. 若不足3个，再从其余未入选板块按整体表现从高到低补足。

### 下跌前三

1. 先收集全部清一色下跌板块；
2. 在这些候选中按既定板块整体表现从低到高排序；
3. 优先取前3；
4. 若不足3个，再从其余未入选板块按整体表现从低到高补足。

**清一色候选即使平均涨跌幅不如混合板块，也拥有更高优先级。整体收益率只能在同级候选中排序或用于补位，不能越过一致性优先级。**

## 板块整体表现

- Finviz直接给值：使用直接值；
- 未直接给值：按Finviz底层节点及方块权重计算；
- 股票板块复算采用市值权重：`Σ(市值×收益率)/Σ市值`。

## 每个入选板块必须披露

- 有效成分数；
- 涨/跌/平家数；
- 涨/跌占比；
- 板块整体收益率；
- 入选身份：`清一色优先` 或 `平均表现补位`；
- 上涨板块：涨幅最大3只真实成分；
- 下跌板块：跌幅最大3只真实成分；
- 不足3只如实列出，不凑数。

## Themes

一致性单位改为**子主题**：

- 全部子主题严格上涨 = 清一色上涨主题大类；
- 全部严格下跌 = 清一色下跌主题大类；
- 含0或方向混合 = 非清一色。

排序顺序完全相同。主题大类无直接值时按全部子主题收益率等权平均。

每个入选主题披露：

- 子主题总数；
- 上涨/下跌/平盘子主题数；
- 方向占比；
- 等权收益率；
- `清一色优先/平均表现补位`；
- 主要子主题贡献；
- 主题全部成分股中对应方向最极端3只股票。

## 最终复核——必须单独输出

对 All Stocks、S&P 500、Dow 30、Nasdaq 100、Russell 2000、Themes 分别列出：

- 清一色上涨候选完整数量；
- 清一色下跌候选完整数量；
- 完整候选名称；
- 最终涨3；
- 最终跌3；
- 哪些属于清一色优先；
- 哪些属于平均表现补位。

这一步必须能够证明：**没有让平均值优先于整体一致性。**

日度使用当日收益率；周度使用1-Week Performance，规则完全相同。
